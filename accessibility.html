מי אנחנו

S-TEAM מאמינה שכל אדם רשאי לגשת למידע ולשירותים דיגיטליים ללא מגבלה. אנו פועלים להנגשת האתר בהתאם לתקן הישראלי ת"י 5568 ולהנחיות WCAG 2.1 ברמת AA.

אמצעי נגישות שיושמו

  • ✓ בוצע כל האתר RTL ובעברית תקנית
  • ✓ בוצע מבנה semantic: h1, h2, main, footer, nav
  • ✓ בוצע alt text לכל התמונות
  • ✓ בוצע ניווט מלא במקלדת (Tab / Shift+Tab / Enter)
  • ✓ בוצע focus-visible ניגודי בכל האלמנטים האינטראקטיביים
  • ✓ בוצע aria-label, aria-required, aria-live בטופס
  • ✓ בוצע כפתור הגדלת טקסט (A+)
  • ✓ בוצע עמידה ב-prefers-reduced-motion
  • ✓ בוצע ניגודיות צבעים ≥ 4.5:1 בכל הטקסטים
  • ⚡ חלקי widget נגישות חיצוני (EqualWeb / UserWay), מתוכנן
